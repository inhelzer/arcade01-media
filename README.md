# arcade01-media

מדיה של אתר מגמת משחקי מחשב, קמפוס פרס.

50 קובצי עמוד הבית נמצאים ב־`home/`, ללא שינוי בבייטים שהתקבלו מהאתר המפורסם. האנימציות נשמרו. `manifest.json` מתעד מקור, קישור יעד, ממדים, פורמט וטביעת SHA-256. אלה גרסאות התצוגה של האתר ולא בהכרח קובצי המקור לעריכה.

קוד האתר: https://github.com/inhelzer/arcade01-site

אין להחיל רישיון כללי חדש על עבודות תלמידים או גרפיקה של צד שלישי. יש לשמור את הקרדיטים וההרשאות הקיימים.
